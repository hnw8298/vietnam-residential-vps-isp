## 先搞清楚你在买什么：双ISP、原生住宅，以及四项核验

「越南家宽VPS」这个说法被用得很松。真正决定它值不值钱的，是IP在数据库里被认成什么。

双ISP属性指的是：这个IP在ping0、scamalytics、IPinfo这类库里，同时被识别为住宅用户IP和ISP类型IP。它模拟的是越南本地家庭宽带的上网特征，而不是数据中心出口。TikTok的风控对DC IP的处理很直接——标记为非真实用户，然后限流、掉流量、封号，一套流程走完。

问题是，市面上不少所谓「越南家宽IP」，实际只是IDC IP或者广播IP。商家说家宽，数据库说hosting，中间差的不是一点点。买之前自己查四项：

- **ASN归属**：这段IP到底挂在哪个运营商名下，是不是本地宽带商
- **ISP信息**：IPinfo的Company字段写的是ISP还是数据中心
- **IP类型识别结果**：ping0一类工具判定为住宅还是机房
- **风控数据库记录**：scamalytics欺诈分、滥用记录、黑名单命中

四项里有一项对不上，就别信宣传页上的「原生家宽」。这套检查清单不花钱，只是花几分钟，比买完发现IP在某个黑名单里躺着划算。
